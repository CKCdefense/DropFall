# 58. 골렘 광역 찍기 — 중심 정렬과 속도 (작업 보고)

화염 골렘의 전방향 찍기(Attack02)가 **판정 원 한가운데 서 있지 않아 보이는** 문제를
고치고, 그 패턴만 재생속도와 시전 시간을 늦췄다.

## 1. 어긋난 건 판정이 아니라 그림이었다

먼저 원점부터 의심했는데 아니었다. 아틀라스를 실측하니 골렘의 발밑은 100px 캔버스의
y=60, 즉 `MONSTER_ORIGIN_Y`(0.6)와 **정확히** 일치한다. 세로는 문제가 없다.

가로가 문제였다. 팩 그림이 캔버스 정중앙에 그려져 있지 않다.

| | 서 있는 자세의 가로 중심 | 캔버스 중앙(50) 대비 | 월드 px(배율 반영) |
|---|---|---|---|
| 화염 골렘 | 52.0 | +2.0 | **+6.0** |
| 다크나이트 | 55.5 | +5.5 | +16.5 |
| 데몬 보스 | 55.0 | +5.0 | +12.5 |
| 미노타우로스 | 56.0 | +6.0 | +6.0 |
| 나머지 | 48.0~53.1 | −2.0~+3.1 | −2.0~+3.1 |

판정(피격 반경·부채꼴·전방향 광역)은 전부 몬스터의 **논리 좌표**를 중심으로 돈다. 즉
논리 좌표가 맞고 그림이 옆으로 밀려 있었던 것이라, **그림을 옮겼다.** 판정은 손대지
않았다 — 반대로 했다면 히트박스가 실제 위치에서 벗어난다.

반전(`flipX`)은 원점을 축으로 도니 치우침도 같이 뒤집힌다. 보정 부호도 같이 뒤집는다.

골렘만 고치면 나머지 아홉 종이 같은 이유로 어긋난 채 남는다. 같은 표에 측정값을 모두
넣어 한 번에 맞췄다 — **보이는 위치만 바뀌고 판정은 그대로다.**

## 2. 그 패턴만 늦췄다

보스 공격은 전부 9fps로 재생하고 있었다. 여기에 **동작별 지정**을 추가했다
(`meleeAttacks[].animFrameRate`).

| | 이전 | 지금 |
|---|---|---|
| 재생속도 | 9fps | **7.2fps** (0.8배) |
| 타격 시점(`atSeconds`) | 0.67초 | **0.84초** |
| 후경직(`recoverSeconds`) | 0.35초 | **0.44초** |

셋을 같은 비율(0.8배)로 늦춘 이유는, `atSeconds`가 원래 **프레임 번호 ÷ 재생속도**로
잡은 값이기 때문이다. 재생만 늦추면 그림이 아직 안 닿았는데 판정이 먼저 나간다.

예고(텔레그래프) 길이는 `atSeconds`에서 파생되므로 자동으로 같이 늘어난다 — 반응할
틈이 그만큼 길어진다. 다른 두 패턴(평타·돌진)은 건드리지 않았다.

## 3. 검증

- 아틀라스 실측: 발밑 y=60(원점과 일치), 서 있는 자세 가로 중심 52.0 → 보정 −6 월드 px
- 브라우저 프로브: 골렘의 등록된 재생속도가 `attack2`만 **7.2fps**, 나머지 공격은 9fps
- shared 536 + server 31 통과, typecheck·lint 깨끗

**원형 예고를 화면에서 직접 재지는 못했다.** 이 패턴은 가중치 3·쿨다운 7초라 촬영
창(수십 초)에 안 걸렸고, 잡힌 것은 돌진 예고(직사각형)였다. 가로 보정은 실측값에
배율을 곱한 산술 변환이라 결과가 확정적이지만, 원이 실제로 몸 한가운데 오는지는
직접 플레이로 한 번 봐 주시면 좋겠다.

## 4. 작업 중에 발견한 것

측정하려고 아틀라스를 읽다가 `packages/client/public/assets/atlas/monsters.json`이
**0바이트**인 걸 발견했다. 몬스터 아틀라스는 비공개 에셋에서 로컬로 빌드하는 파일이라
git에는 없고, 원본(`assets/sprites/monsters/`)은 멀쩡했다 — 빌드가 중간에 끊긴 흔적으로
보인다. `pnpm build:atlas`로 복구했다(145KB). 그 상태로 두면 몬스터가 통째로
플레이스홀더 도형으로 그려진다.

## 5. 남은 것

- 가로 보정은 **서 있는 자세(Idle/Walk) 기준**이다. 공격 동작에서 팔이 뻗으면 그림
  중심은 더 옆으로 가는데(골렘 Attack02는 프레임6에서 +11), 그건 동작이지 서 있는
  위치가 아니라 보정하지 않았다.
- 세로는 전 종류가 원점과 일치해서 손대지 않았다.
