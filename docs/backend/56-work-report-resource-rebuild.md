# 56. 자원 시스템 리빌딩 (작업 보고)

나무/돌은 **자원 게이지**로, 몬스터 드랍은 **에너지 게이지**로 바꾸고, 그 사이에
**코어 충전**을 끼워 넣었다. 돈을 없앴고, 제작에 시간이 생겼고, 레벨업이 들어왔다.

## 1. 무엇이 달라졌나

| | 예전 | 지금 |
|---|---|---|
| 건축·제작·수리 | 창고의 나무/돌 개수 | **자원 게이지** |
| 코어 강화 | 에너지 숫자 | **자원 + 에너지 둘 다** |
| 상점 구매 | 돈(G) | **에너지** |
| 상점 판매 | 드랍 → 돈 | **없앴다** |
| 나무·돌·드랍의 쓰임 | 직접 비용 | **충전 재료** |
| 제작 | 즉시 완성 | **2초** |
| 성장 | 음식뿐 | **경험치·레벨·SP** |

## 2. 왜 개수가 아니라 게이지인가

창고에 든 나무 개수를 그대로 비용으로 쓰면 **창고 20칸이 사실상 전력의 상한**이 된다.
게이지로 바꾸면 상한이 코어 강화로 자라고, 재료 종류가 늘어도 비용 표는 숫자 하나다
(예전 레시피는 `{wood, stone, drop_normal, drop_rare}` 네 축이었다).

그 대가로 **재료를 게이지로 바꾸는 단계**가 필요해졌다 — 그게 코어 충전이다.

## 3. 코어 충전

코어 탭 아래쪽 슬롯 3칸에 재료를 끌어다 놓으면 시간에 걸쳐 게이지가 된다.

슬롯이 셋인 이유는 자원과 에너지를 동시에 채울 수 있어야 해서다 — 하나뿐이면 나무를
태우는 동안 드랍을 못 넣는다. 즉시 변환이 아닌 이유는 밤이 오기 전에 무엇을 먼저
채울지 고르게 만들려는 것이다(초당 2개).

**게이지가 가득 차면 멈추고 재료는 슬롯에 남는다.** 넘치는 만큼을 버리면 언제 다 탔는지
모른 채 재료가 사라지고, 자동으로 되돌려주면 슬롯이 비어 무엇을 넣었는지 잊는다.
남겨 두면 화면만 봐도 "가득 차서 멈췄다"가 읽힌다.

태울 수 없는 물건(무기 등)은 **아예 들어가지 않는다.** 넣어 두고 아무 일도 안 일어나면
"왜 안 타지"가 되므로, 슬롯이 거절해서 화면에서 보이게 했다.

소수점 진행분을 슬롯마다 들고 다닌다 — 틱마다 내림하면 60Hz에서 "초당 2개"가 매번
0개로 잘려 영원히 아무것도 안 탄다.

## 4. 돈을 없앴다

돈과 에너지가 따로 있으면 "판 돈으로 산다"와 "모아서 강화한다"가 서로 무관해져서,
밤에 번 것이 무엇에 쓰이는지가 두 갈래로 흩어진다. 에너지 하나로 합치고 상점을
그쪽에 붙였다.

**판매도 같이 없앴다.** 드랍은 충전을 거쳐 에너지가 되는데, 판매까지 두면 같은 일을
하는 경로가 둘이 되고 "충전은 시간이 드는데 판매는 즉시"라 아무도 충전하지 않게 된다.

## 5. 코어 강화

비용이 **자원과 에너지 둘 다**다. 한쪽만으로 올릴 수 있으면 낮(채집)이나 밤(전투) 중
하나를 건너뛰는 공략이 생긴다.

효과: 코어 체력 +, 자원/에너지 **상한** +, 건설 가능 반경 +. 상한만 늘리고 게이지는
채워 주지 않는다 — 강화 직후 비는 게 "다시 모아야 다음 단계"라는 리듬을 만든다.

강화 버튼은 **코어 탭 안**으로 들어왔다. 예전엔 별도 창(UpgradeModal)이라 "얼마 모였나"를
보고 "올릴까"를 정하는 사이에 창을 갈아타야 했다. 그 창은 지웠다.

## 6. 제작과 수리

제작에 2초가 걸리고, **비용은 먼저 나간다.** 진행 중에 남이 같은 자원으로 다른 걸
만들어 버리면 완성 순간에 실패해야 하는데, 그때는 이미 기다린 뒤라 설명할 방법이 없다.
창고가 꽉 차 결과물이 못 들어가면 비용을 돌려준다.

울타리·벽은 한 번에 6개가 나온다(개당 비용은 그대로 두고 묶음만 키웠다).

**해머로 건축물을 때리면 수리된다.** 별도의 수리 모드나 키를 만들지 않은 이유는, 해머는
이미 "짓는 도구"라 벽을 향해 휘두르는 동작이 곧 고치는 것으로 읽히기 때문이다. 자원
노드와 같은 이유로 **가장 가까운 하나만** 고친다 — 한 번에 벽 다섯 개가 차오르면 수리
비용이 의미를 잃는다.

## 7. 레벨업

경험치는 몬스터 처치로만 오르고, **살아 있는 모두에게 같은 양**이 들어간다(나눠 주는 게
아니다). 막타를 친 사람만 주려면 투사체마다 쏜 사람을 실어 날라야 하고 그 사람이 죽거나
나가면 경험치가 증발한다. 무엇보다 드랍을 바닥에 떨어뜨린 것과 같은 이유다 — 막타로
보상이 갈리면 협동이 아니라 킬 경쟁이 된다. 쓰러진 사람은 못 받는다.

레벨업마다 SP 1점. 캐릭터 창의 `[+]` 버튼이 이제 실제로 동작한다(체력 +12 / 스태미나 +10 /
공격력 +2). 되돌리기는 없다 — 넣으면 밤마다 최적으로 갈아끼우는 게 정답이 되어 선택이
선택이 아니게 된다.

경험치 바는 하단 바의 체력·스태미나 **아래**에 줄 전체 폭으로 얇게 깔린다. 얇은 이유는
급하지 않은 정보라서다 — 체력은 죽고 사는 문제라 두껍게, 경험치는 곁눈질로 진행도만
보면 된다.

레벨업 이펙트(`fx_levelup.lua`)는 발밑에서 빛 기둥이 서고 고리가 퍼진다. 음식의 스탯
상승(`fx_boost/statup`)과 헷갈리면 안 되므로, 그쪽(금빛 화살표 하나)과 실루엣을 확실히
다르게 잡았다. 캐릭터 **뒤에** 깐다 — 기둥이 몸을 덮으면 정작 레벨이 오른 사람이 안 보인다.

## 8. 검증

- shared 530 + server 31 통과. 신규 16개(`resource-rebuild.test.ts`) — 충전 변환·시간·
  60Hz 소수점 누적·가득 참 정지·거절, 해머 수리 4종, 경험치 분배·다중 레벨업, SP 3종.
  기존 25개는 새 규칙에 맞춰 고쳤다(창고 개수 → 게이지, 판매 테스트 삭제).
- 헤드리스 크롬:
  - 코어 탭에 게이지 셋 + 강화 버튼 + 충전 슬롯 3칸
  - 인벤토리 나무 40개를 충전 슬롯에 **드래그** → 슬롯에 34개 남고 자원 18/400 (2개/초 × 3)
  - 강화 → 체력 1000→1300, 자원 400→150(250 차감)·상한 400→800, 에너지 150→90·상한 150→300,
    다음 단계 비용이 자원 700·에너지 200으로 갱신
  - 제작 "돌도끼 만드는 중... 1.5초", 비용 "자원 800/110"
  - 상점 "에너지 300", 상세 "에너지 100 · 무기", 판매 구역 없음
  - `level 4` → 레벨업 빛 기둥 재생, 캐릭터 창 Lv 4 / SP 3 → `[+]` 두 번 → SP 1,
    체력 100→112, 공격력 0→2
  - 콘솔 오류 없음(favicon 404만)

## 9. 남은 것

- 수치는 **첫 통과 값**이다. 나무 3 / 돌 5 / 부품 3 / 희귀부품 12로 환산했고 건축·제작
  비용은 예전 값을 그 환산으로 옮긴 뒤 게이지 상한에 맞게 다듬었다 — 실제로 한 판
  돌려 보면 조정이 필요할 것이다.
- 충전 슬롯에서 아이템을 도로 빼는 건 드래그로만 된다(전부 빼기 버튼 없음).
- 창고의 나무/돌은 이제 충전 말고는 쓸 데가 없다. HUD 상단의 "창고 나무/돌/부품" 표시는
  그래서 남겨 뒀다 — 코어로 돌아갈지 판단하는 값이다.
- SP는 스탯 셋에만 쓴다. 직업 스킬은 아직 자리만 있다.
