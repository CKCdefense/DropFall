# 54. 들고 다니는 건축물 (작업 보고)

울타리·벽을 **인벤토리 아이템**으로 만들어 손에 들고 바닥에 설치할 수 있게 했다. 티어
2·3(돌·철)도 함께 추가했다.

## 1. 무엇이 달라졌나

예전에는 건축이 하나뿐이었다 — 건축 모드(B)로 켜고, 코어 창고의 나무·돌을 그 자리에서
빼서 지었다. 창고 자원은 코어 앞에서만 쓸 수 있는 자원인데 벽은 멀리 나가서도 세우고
싶다. 그래서 **아이템 경로**를 하나 더 뒀다.

| | 건축 모드(B) | 손에 든 아이템 |
|---|---|---|
| 무엇을 지을지 | 모드로 고른다 | 선택한 칸에 든 것 |
| 비용 | 코어 창고의 나무·돌 | 아이템 한 개 |
| 언제 쓰나 | 코어 근처에서 즉석으로 | 낮에 만들어 두고 밤에 들고 다니며 |

두 경로는 **자리 규칙을 공유한다**(`World.canPlaceBuildingAt`). 규칙이 두 벌이면 한쪽만
고쳐져서 조용히 갈라진다 — 실제로 배치 검사는 여섯 가지(경계·중복·건설 반경·코어 발자국·
자원 노드·사람)나 되어 복사할 만한 크기가 아니다.

## 2. 티어

나무(1) → 돌(2) → 철(3). 울타리는 총알이 지나가고 벽은 막는다는 규칙은 그대로다.

| | 울타리 hp | 벽 hp |
|---|---|---|
| 나무 | 50 | 200 |
| 돌 | 120 | 420 |
| 철 | 260 | 900 |

철은 창고 자원(`woodCost`/`stoneCost`)이 0이다 — **제작으로만** 얻는다. 건축 모드로
공짜로 지어지는 걸 막으려면 그쪽 비용을 0으로 두면 안 되는데, 애초에 건축 모드에는
철이 없다(모드 목록은 나무 둘뿐이다).

레시피는 한 번에 여러 개가 나온다(울타리 5, 벽 3). 울타리를 한 개씩 만들게 하면 같은
버튼을 스무 번 누르게 된다. 이를 위해 레시피에 `count`를 넣었고, **일부만 창고에 들어가면
통째로 되돌린다** — "다섯 개 만들었는데 두 개만 생겼다"를 설명할 방법이 없다.

## 3. 스프라이트

`assets/_generators/buildings_tiers.lua`가 8프레임(돌·철 × 벽·울타리 × 정면·측면)을 만든다.

기존 나무 에셋을 실측해 **같은 자리에 그린다** — 타일이 캔버스 가운데가 아니라 x 7~23,
바닥선 y 28에 놓여 있다. 이걸 맞춰야 새 건축물이 기존 것과 한 줄에 섰을 때 바닥이
어긋나지 않는다. 실루엣도 그대로 따랐고(벽은 꽉 찬 상자, 울타리는 가운데가 뚫린 틀)
재질만 바꿨다 — 돌은 어긋난 줄눈의 벽돌, 철은 세로 이음매와 리벳.

벽돌 밝기는 고정 시드로 살짝 흔든다. 완전히 규칙적이면 기계로 찍은 무늬처럼 보여서,
손으로 찍은 나무 에셋 옆에 두면 혼자 붕 뜬다. 울타리 가운데를 도려낼 때 모서리에
떨어져 나오는 낱개 픽셀은 지운다(그대로 두면 외곽선까지 입혀져 먼지처럼 보인다).

## 4. 설치 미리보기

건축 아이템을 들면 커서가 가리키는 칸이 초록(가능)/빨강(불가)으로 비친다.

**서버는 배치를 거절해도 아무것도 돌려주지 않는다**(`placeBuilding`은 void다). 미리
보여주지 않으면 왜 안 지어지는지 알 방법이 전혀 없다. 판정은 서버와 같은 규칙을
스냅샷으로 다시 계산한다. 여기서 통과했는데 서버가 거절하는 경우(같은 틱에 남이 먼저
지었다)는 남지만, 그건 미리보기가 틀린 게 아니라 정보가 한 틱 오래된 것이다.

건축 모드(B)로 지을 때도 같은 표시를 쓴다 — 두 경로가 결국 같은 칸에 같은 규칙으로
짓는데 표시가 다르면 헷갈린다.

## 5. 손에 든 것을 그린다

무기가 아닌 아이템(붕대·재료·건축물)도 손에 그려진다. 예전엔 무기가 아니면 전부 맨손이라
붕대를 들었는지 돌을 들었는지 화면에서 알 수 없었다.

무기와 **같은 배치 규칙**(궤도·회전·휘두르기)에 얹었다. 그래서 별도 코드 없이 조준
방향을 따라 돌고, 좌클릭하면 맨손과 같은 공격 모션이 나온다 — 판정도 맨손(`fist`)이라
그림과 규칙이 이어진다. 크기는 아이템마다 원본 캔버스가 제각각이라(재료 64px, 소모품
32px) 그림이 실제로 차지하는 영역을 기준으로 목표 크기에 맞춘다.

소모품은 예전처럼 좌클릭이 **사용**이다(공격이 아니라). 재료처럼 쓸 데가 없는 것만
공격으로 간다.

## 6. 검증

- shared 492 + server 31 통과. 신규 5개 — 아이템 소모·창고 불변·건축 아이템이 아닐 때
  무시·실패 시 아이템 보존·미리보기와 실제 배치가 같은 규칙
- 헤드리스 크롬: 돌 벽/철 울타리 설치와 렌더, 커서 미리보기 초록·빨강, 손에 든 붕대·나무
  렌더, 재료로 공격 시 휘두르기 이펙트

테스트를 짜다 하나 배웠다 — 코어 발자국은 생각보다 넓어서(가장자리 반경 ~52px) 코어에서
60px 떨어진 칸도 아직 키프아웃 안이다. 처음 고른 테스트 칸이 여기 걸려서 옮겼다.

## 7. 남은 것

- 건축 모드(B) 목록에는 여전히 나무 울타리·벽뿐이다. 돌·철은 아이템으로만 세운다.
- 설치는 낮/밤을 가리지 않는다(기존 건축과 같다).
- 철거하면 아이템으로 돌아오지 않는다(기존 규칙 유지 — 환급 없음).
