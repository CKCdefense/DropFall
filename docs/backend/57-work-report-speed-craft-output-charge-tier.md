# 57. 이동속도 절반, 제작 대기 칸, 티어별 충전 칸 (작업 보고)

이동속도를 전원 절반으로 낮추고, 제작 결과를 창고 대신 **꺼내 가는 칸**에 두고, 충전
칸 수를 코어 티어에 묶었다.

## 1. 이동속도 절반

| | 이전 | 지금 |
|---|---|---|
| 플레이어 | 100 | 50 |
| 몬스터 | 28~130 | 14~65 |
| 티모시 | 110 | 55 |

**보스 돌진(`attacks[].dash.speed`)은 그대로 뒀다.** 그건 이동이 아니라 공격이고,
사거리·예고 시간과 맞물려 있어 같이 줄이면 패턴 자체가 달라진다.

티모시도 같이 줄였다. "모든 몬스터 및 플레이어"에 그는 안 들어가지만, 혼자 두 배로
빠르면 옆에서 뛰어다니는 것처럼 보인다.

이동 테스트 넷이 깨졌다. 원점(0,0)에서 1초 한 틱으로 움직이는 테스트였는데, 속도가
절반이 되자 **코어 발자국을 못 벗어나 충돌에 막혔다.** 이 테스트들이 보려는 건 입력
처리이지 코어 충돌이 아니라, 출발점을 발자국 밖(500,500)으로 옮겼다.

건축물 테스트도 하나 손봤다 — "몬스터가 제자리 그대로"라고 못 박았는데, 느려지면서
벽 사거리 안까지 붙는 데 한 걸음이 더 필요해졌다. 보려는 건 "플레이어를 쫓지 않는다"라
그쪽으로 다시 적었다.

## 2. 제작 결과는 꺼내 가는 칸에

완성품이 창고로 바로 들어가면 스무 칸 어딘가에 섞여 **무엇이 새로 생겼는지 알 수 없다.**
이제 제작 칸에 남고, 드래그로 인벤토리에 가져간다.

- 결과 칸이 차 있으면 **다음 제작을 걸 수 없다.** 덮어쓰면 앞의 결과가 사라진다.
- 결과 칸은 **꺼내 가기 전용**이다 — 넣으려 하면 되돌려준다. 보관함이 아니다.
- 화면은 서버가 들고 있는 값(`craftOutput`)을 그대로 비춘다. 예전엔 "제작 중이던
  레시피가 사라진 순간"으로 클라가 완성을 추측했는데, 결과가 남아 있으니 추측할 이유가
  없어졌다.

## 3. 충전 칸은 코어 티어만큼

티어 1 → 1칸, 2 → 2칸, 3 → 3칸. 잠긴 칸은 **지우지 않고 흐리게 남긴다**("잠김") —
강화하면 늘어난다는 걸 계속 보여준다.

배열 자체는 최대 개수(3)로 잡아 두고 앞에서부터 티어만큼만 연다. 티어가 오를 때 배열을
늘리면 이미 담긴 재료의 칸 번호가 흔들린다.

## 4. 쉬프트 클릭으로 충전

목적지를 **지금 열려 있는 탭**이 정한다 — 코어 탭이면 충전 칸, 그 밖에는 예전대로
창고다. 쉬프트 클릭 하나가 두 곳을 가리키게 됐는데, 눈에 보이는 곳으로 가는 게 가장 덜
놀랍다. 서버는 목적지를 명시적으로 받는다(안 보내면 예전 규칙 그대로).

같은 재료가 이미 타고 있으면 거기 합치고, 없으면 열린 빈 칸을 쓴다.

## 5. 거절은 붉게 깜빡인다

태울 수 없는 물건을 넣으려 하면 그 칸 테두리가 붉게 세 번 깜빡인다.

**서버에 보내 보고 거절당하길 기다리지 않는다** — 아무 일도 안 일어나는 것과 거절당한
것을 화면에서 구분할 수 없기 때문이다. 판정은 서버와 같은 규칙(`World.canCharge`)이라
어긋나지 않는다. 잠긴 칸에 놓으려 할 때도 같은 신호를 준다.

## 6. 검증

- shared 536 + server 31 통과. 신규 8개 — 제작 결과 칸(창고로 안 감·꺼내 가기 전 재제작
  금지·꺼내기/넣기), 충전 칸 티어 게이트, 쉬프트 클릭 충전 3종
- 헤드리스 크롬:
  - 충전 칸: 티어 1에서 `비었음 / 잠김 / 잠김`, `tier 3` 뒤 세 칸 모두 열림
  - 쉬프트 클릭으로 나무 20개가 1번 칸에 들어감
  - 권총을 쉬프트 클릭 → 칸이 **붉게 깜빡였다가** 원래 색으로 복귀
  - 제작 완료 후 결과 칸에서 인벤토리 4번 칸으로 **드래그 성공**(결과 칸이 비고 화살표도 초기화)
  - 콘솔 오류 없음

작업 중에 하나 걸렸다 — 처음엔 드래그가 시작조차 안 됐다. `SlotDrag`는 칸에
`setInteractive`가 이미 걸려 있어야 `pointerdown`을 받는데, 새로 만든 결과 칸과 충전
칸에 그게 빠져 있었다. 충전 칸은 **놓기만** 하면 기하 판정(`cellAt`)으로 되므로 드롭은
멀쩡히 동작했고, 그래서 "빼는 것"을 해보기 전까지 드러나지 않았다.

## 7. 남은 것

- 속도를 절반으로 낮췄으니 **웨이브 밸런스는 다시 봐야 한다.** 몬스터가 코어까지 오는
  시간이 두 배가 됐으므로 밤 길이나 스폰 간격이 헐거워졌을 수 있다.
- 결과 칸은 한 칸이다. 여러 개를 쌓아 두고 나중에 한꺼번에 가져갈 수는 없다.
- 쉬프트 클릭은 창고 → 충전을 지원하지 않는다(인벤토리에서만).
