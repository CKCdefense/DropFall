# 로드맵 / 역할 분담

3인 팀, 공모전 데모 제출 기준. 기간은 **W1 = 착수 1주차** 상대 표기.
실제 제출일이 확정되면 이 문서를 절대 날짜로 갱신한다.

---

## 개발 원칙 (공모전용)

1. **완성 > 기능 수.** 미완성 기능 10개보다 완성된 5개가 심사에서 이긴다.
2. **플레이스홀더 우선.** 단색 사각형으로 전 시스템을 먼저 굴리고, 아트는 나중에 교체한다.
3. **멀티를 뒤로 미루지 않는다.** 가장 큰 리스크는 가장 먼저 친다.
4. **매주 금요일 = 플레이 가능한 빌드.** 안 되면 그 주 범위를 잘라낸다.
5. 마지막 1주는 **신규 기능 금지.** 밸런싱, 버그, 폴리시만.

## 역할 분담 (3인)

역할은 고정이 아니라 **오너십**이다. 해당 영역의 결정권과 리뷰 책임을 진다.

| 역할 | 담당 영역 | 주 작업 |
|---|---|---|
| **A — 서버/네트워크** | `server/`, `shared/sim`, `client/net` | Colyseus 룸, 권위 시뮬, 동기화, 예측/보간, AI(Flow Field), 배포 |
| **B — 게임플레이** | `shared/sim`, `shared/data`, `client/` | 전투, 건축, 자원, 성장, 웨이브, 밸런스 데이터 |
| **C — 클라/아트/UI** | `client/render`, `client/ui`, `assets/` | 스프라이트, 맵, 아틀라스 파이프라인, HUD/상점/인벤토리 UI, 이펙트 |

- `shared/sim`은 A와 B가 공유한다. **파일 단위로 나눠** 충돌을 줄인다
  (A: `world`, `movement`, `ai` / B: `combat`, `building`, `wave`)
- 에셋 바이너리는 C만 커밋한다 ([Git 컨벤션 §5](03-git-convention.md))
- W2(멀티 동기화)는 예외적으로 전원 투입

## 정기 일정

| 주기 | 내용 |
|---|---|
| 매일 | 각자 진행/블로커 한 줄 공유 (채널) |
| 주 2회 | 30분 동기화 회의 — 진행 상황, 결정 필요 사항 |
| 매주 금 | 통합 빌드 + 3인 플레이테스트 |
| 매주 금 | 다음 주 범위 확정 (못 하면 잘라낸다) |

## 범위 조정 우선순위

일정이 밀리면 아래 순서로 **잘라낸다.** 미리 정해둬야 급할 때 싸우지 않는다.

**절대 사수 (P0)**
멀티 접속 · 이동/사격 · 몬스터 웨이브 · 코어 HP · 승패 · 기본 건축(벽/울타리) · 낮/밤 사이클

**여유되면 (P1)**
직업 3종 · 스킬 트리 · 상점 · 무기 다양화 · 포탑 · 다운/부활

**과감히 포기 (P2)**
테크 트리 · 보스 · 원거리/탱커 몬스터 · 사운드 · 회피 구르기 · 4번째 직업 · 맵 여러 개

> 웨이브 수는 5개로 충분하다. 10웨이브를 목표로 잡다가 5웨이브도 못 끝내는 게 최악이다.
