## 문서 규칙

- 문서 변경도 코드와 동일하게 PR로 올린다 (`docs:` 커밋 타입).
- 결정이 바뀌면 문서를 고친다. 문서와 코드가 다르면 **문서가 틀린 것**으로 간주하고 즉시 갱신한다.
- 확정되지 않은 안은 `> TBD:` 로 표기해 남겨둔다.
