# 19. 이펙트 정렬과 문구 굵기 (작업 보고)

소모품 이펙트가 캐릭터에서 13px 아래로 밀려 있던 것을 고치고, 레벨업 연출을 미니멀하게
다시 만들고, 화면 중앙 문구를 굵고 크게 바꿨다.

## 1. 이펙트가 13px 아래에 있었다

회복·버프·스탯 이펙트를 캐릭터 위치에 **캔버스 한가운데(0.5)를 맞춰** 올리고 있었다.
그런데 이 그림들은 캔버스 가운데가 아니라 **아래쪽에 바닥선이 그려져 있다**.

| | 캔버스 | 생성기의 GROUND | 중앙과의 차이 |
|---|---|---|---|
| fx_heal / fx_boost | 40px | 33 | **+13px** |
| fx_levelup | 48px | 40 | +16px |

그래서 발밑 고리가 캐릭터 발이 아니라 그보다 13px 아래 땅에 떠 있었다. 원점을
`GROUND / 캔버스 높이`로 잡아 **그림의 바닥선이 캐릭터 발밑에 오게** 했다.

세로만 어긋나 있었다 — 가로는 생성기의 CX가 캔버스 중앙(19.5/40)이라 맞았다.

## 2. 레벨업을 미니멀하게

예전엔 금빛 빛기둥에 발밑 고리 두 겹·불티 열 개·별 광채까지 얹은 10프레임이었다.
**레벨업은 캐릭터에게 일어나는 일이지 화면에 일어나는 일이 아닌데**, 거창한 연출이
정작 레벨이 오른 캐릭터를 가렸다.

지금은 두 가지뿐이다.

- **캐릭터가 하얗게 세 번 점멸한다.** 그림이 아니라 스프라이트 틴트로 낸다(피격 플래시와
  같은 문법) — 어떤 직업이든 같은 실루엣으로 반응하고, 직업마다 그림을 그릴 필요가 없다.
- **하얀 빛기둥이 한 번 번쩍한다.** 6프레임, 0.43초.

두 가지를 조심했다.

- **기둥을 캐릭터보다 확실히 가늘게** 잡았다(반폭 3px vs 캐릭터 14px). 비슷하게 굵으면
  하얗게 점멸하는 캐릭터와 한 덩어리로 뭉쳐 실루엣이 통째로 사라진다.
- **점멸을 기둥보다 0.16초 늦게** 시작한다. 동시에 터뜨렸더니 같은 이유로 뭉쳤다.

기둥은 속을 꽉 채워 그리고 사라짐은 **알파로** 처리한다. 그림에서 밝기를 디더로 표현하면
기둥이 얼룩덜룩해져서 "빛"이 아니라 "무늬"로 보인다(처음에 그렇게 만들었다).

## 3. 문구를 굵고 크게

`Galmuri11-Bold`가 이미 weight 700으로 등록돼 있어서(`ui/fonts.ts`) `fontStyle: 'bold'`
한 줄이면 된다. 화면을 가로지르는 큰 글자는 기본 굵기로는 획이 가늘어 배경에 묻혔다.

크기는 99 → **132px**(11 × 12). 픽셀 폰트는 설계 크기의 정수배에서만 선명하다.

## 4. 검증

- **정렬**: 붕대를 쓰면 초록 십자가가 몸 주위로 오르고 발밑 고리가 **신발 높이**에 온다
  (고치기 전에는 그보다 13px 아래)
- **레벨업**: 기둥이 발밑에서 번쩍한 뒤 캐릭터가 흰 실루엣으로 점멸하고 원래대로 돌아온다
- **문구**: `DAY 1`이 굵은 획으로 크게 뜬다
- shared 537 + server 31 통과

## 5. 남은 것

- 이펙트 원점 비율(33/40)이 렌더러에 **상수로 박혀 있다.** 생성기의 GROUND를 바꾸면
  여기도 같이 고쳐야 한다 — 그림 쪽에 메타데이터를 심을 방법이 없어서 지금은 주석으로
  연결해 뒀다.
- 레벨업 점멸은 **내 캐릭터든 남의 캐릭터든** 똑같이 보인다(구분 표시 없음).
