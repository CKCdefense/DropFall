# 16. 혼자하기 설정과 티모시 켜고 끄기 (작업 보고)

혼자하기에 **직업 선택 모달**을 붙이고, 멀티·싱글 모두 시작 전에 **티모시를 켜고 끌 수**
있게 했다.

## 1. 혼자하기에 직업 선택이 없었다

혼자하기는 대기실을 건너뛰고 곧장 게임으로 들어간다(`LocalConnection.getLobbyView()`가
처음부터 `PLAYING`을 돌려준다 — 혼자라 준비할 상대가 없다). 그런데 직업을 고르는 자리가
**대기실뿐이었다.** 그래서 혼자 하면 언제나 기본 스탯(`jobsData.base`)으로 시작했다.

멀티의 대기실을 혼자하기에도 붙이는 대신, 시작 버튼과 게임 사이에 **설정 모달** 하나를
뒀다. 대기실은 남을 기다리는 화면인데(슬롯 4칸·준비 상태·방장) 혼자서는 그 절반이
빈 자리로 남는다.

고르지 않으면 시작할 수 없다 — 멀티에서 직업 없이 준비를 못 하는 것과 같은 규칙이다.

직업 칩(`.job-chip`) 대신 **초상화가 있는 카드**를 쓴다. 대기실은 슬롯에 얼굴이 이미
크게 떠 있어 칩으로 충분하지만, 이 모달은 대기실 전체를 대신하므로 고르는 자리에서
얼굴이 보여야 한다. 초상화는 대기실과 같은 방식으로 아틀라스 PNG를 잘라 쓴다.

## 2. 티모시 켜고 끄기

체크박스는 **혼자하기 모달**과 **방 만들기 모달** 두 곳에 있고, 같은 조각
(`companionToggle()`)을 쓴다. 같은 설정이 화면마다 다르게 생기면 같은 값이라는 걸
알아보기 어렵다. 값도 하나를 공유한다 — 한 번 정한 취향이 다음 판에도 이어지는 게
자연스럽고, 두 화면이 서로 다른 값을 기억하면 "분명 껐는데 켜져 있다"가 된다.

**멀티는 참가 쪽이 아니라 방 만들기에 뒀다.** 티모시는 방당 1마리라 참가자가 각자 켜고
끌 수 있는 값이 아니다. 대신 대기실이 꺼진 방에서만 한 줄로 알려준다("이 방은 티모시
없이 진행한다") — 켠 쪽은 기본값이라 굳이 자리를 쓰지 않는다.

**게임 도중에는 바뀌지 않는다.** 티모시가 중간에 생기거나 사라지면 자원 수급과 몬스터
어그로가 통째로 달라진다. 그래서 월드를 세울 때 한 번만 정한다(`WorldOptions.companion`).

## 3. "없음"을 어떻게 표현했나

티모시 필드를 `null`로 두지 않고 **상태 하나(`'absent'`)를 추가**했다.

티모시는 World·스냅샷·보간·렌더러를 관통해 스무 곳 넘게 등장한다. 필드를 nullable로
만들면 그 전부가 물음표 연산자로 덮이고, 그러면 "없는 방"과 "아직 스냅샷이 안 온 순간"이
구분되지 않는다. 상태 하나면 이미 있던 `state !== 'downed'` 검사 자리에 그대로 얹힌다.

다만 그 검사가 **여섯 군데**였다 — 표적 선정, 평타, 보스 돌진, 보스 검술, 광역기,
수확 루프. 한 곳만 빠뜨려도 없는 티모시를 몬스터가 때리러 간다. 그래서 전부
`companionActive()` 하나로 모았고, 이 함수가 `downed`와 `absent`를 같이 본다.

`absent`는 `downed`와 다르다 — 다운은 낮이 되면 되살아나지만 이건 처음부터 없는 것이라
영영 바뀌지 않는다. 부활 훅에 가드를 따로 뒀다(안 두면 첫 아침에 티모시가 생겨난다).

## 4. 검증

- shared 512 + server 31 통과. 신규 5개 — 끈 방은 수확을 안 한다 / 낮이 와도 안 생긴다 /
  말을 걸면 거절한다 / **몬스터가 때리지 않는다** / 옵션을 안 주면 기존대로 켜져 있다
- 헤드리스 크롬:
  - 직업 안 고르고 시작 → 거절되고 모달 유지
  - 의무병 선택 후 시작 → 체력 105·스태미나 115 (병사는 125·95). 기본값이 아니다
  - **50초 방치 후 코어 창고**: 티모시 켬 `나무 150 · 돌 45` / 끔 `나무 0 · 돌 0`
  - 멀티(방 만들기에서 끔) → 대기실에 안내 한 줄, 게임 시작 후 50초에도 `나무 0 · 돌 0`
  - 콘솔 오류 없음

창고 숫자로 확인한 이유는, 티모시가 시작하자마자 자원을 찾아 화면 밖으로 걸어 나가서
스크린샷에 안 잡히기 때문이다. "안 보인다"는 껐다는 증거가 못 된다.

## 5. 남은 것

- 방을 만든 뒤에는 티모시 설정을 바꿀 수 없다(대기실에서 토글하려면 월드를 다시 세워야
  한다).
- `?local=1` 직행 경로는 여전히 로비를 안 거치므로 기본 스탯 + 티모시 켬으로 시작한다
  (개발용 경로라 그대로 뒀다).
- 혼자하기 모달에 직업별 상세 스탯은 없다 — 한 줄 요약(`화력`, `치유·부활`)만 보여준다.
