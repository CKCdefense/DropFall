# 17. 걷기 모션 복구와 조작·안내 개선 (작업 보고)

걷기 애니메이션이 안 돌던 버그를 고치고, 소모품 사용을 우클릭으로 옮기고, 휠로 퀵슬롯을
넘길 수 있게 했다. 코어 위에 `E` 키 안내를 띄우고, 제작에 진행 화살표와 결과 상자를 붙였다.

## 1. 걷는 모션이 안 나왔다

캐릭터가 미끄러지듯 이동하고 팔다리가 전혀 안 움직였다.

원인은 **"이번 프레임에 좌표가 안 변했으면 즉시 `anims.stop()`"** 이었다. 좌표는 매 렌더
프레임 바뀌지 않는다 — 서버 스냅샷은 20Hz고 화면은 60fps라, 보간기가 다음 스냅샷을
기다리는 동안 두세 프레임이 같은 좌표로 나온다. 그때마다 애니메이션을 멈추고 다음
프레임에 다시 `play`가 걸리니 **영원히 첫 프레임에 머물렀다.**

브라우저에서 실제로 확인했다 — `isPlaying`이 `P x P P x x P …`로 깜빡이고 프레임은
`_0`에서 한 번도 벗어나지 않았다.

몬스터는 이미 같은 문제를 유예 카운터로 풀고 있었다(`stillFrames < 6`). 플레이어에도
같은 규칙을 적용하고, 흩어져 있던 숫자를 `STILL_GRACE_FRAMES` 하나로 합쳤다.

## 2. 소모품은 우클릭, 좌클릭은 공격

좌클릭 하나에 공격과 사용이 겹쳐 있어서 **붕대를 들고 몬스터를 때릴 방법이 없었다.**

- **좌클릭은 언제나 공격이다** — 무기를 들었으면 그 무기로, 아니면 맨손으로.
- **우클릭이 사용이다.** 건축모드에서는 우클릭이 "나가기"라 그쪽이 우선한다.

우클릭 쪽에는 홀드 연타 방지 타이머를 두지 않았다 — 누른 순간에만 도는 이벤트라 구조상
연타가 안 된다. 예전 좌클릭 경로는 매 프레임 도는 루프였기 때문에 타이머가 필요했다.

## 3. 휠로 퀵슬롯 넘기기

숫자키(1~4)는 그대로 두고 휠을 더했다. 전투 중에 손가락을 WASD에서 떼지 않고 바꿀 수
있다. 양끝에서 돌아온다(4에서 아래로 굴리면 1).

기준이 되는 "지금 칸"은 **스냅샷에서 읽는다.** 클라이언트가 따로 세어 두면 숫자키로
바꿨을 때 어긋난다.

## 4. 코어 위 `E` 안내

하얀 키캡 + 아래 화살표를 코어 위에 띄우고 천천히 오르내리게 했다
(`assets/_generators/ui_keyprompt.lua`).

글자를 폰트로 찍지 않고 5×7 비트맵으로 그린 이유는, 폰트는 픽셀 격자에 안 맞아 한
픽셀씩 흐려지기 때문이다. 게임 안에서 항상 같은 크기로 뜨므로 비트맵 하나면 충분하다.

스프라이트의 원점을 **아래쪽(0.5, 1)** 에 뒀다 — 화살표 끝이 곧 "가리키는 지점"이라
띄우는 높이만 정하면 된다. 판정은 서버와 같은 함수(`isWithinCoreInteract`)를 쓴다.
처음엔 96px 위에 뒀는데 코어와 한 덩어리로 안 읽혀서 80px로 내렸다.

## 5. 제작 진행 화살표와 결과 상자

상세 줄이 `[재료] → (차오르는 화살표) → [결과 상자] [제작]`이 됐다. 누른 뒤 시선이 그
자리에 머문 채로 진행과 결과를 다 볼 수 있다.

화살표는 **마스크를 쓰지 않고 채운 만큼만 다시 그린다.** 모달은 끌어서 옮길 수 있어서
도형 마스크를 쓰면 창을 옮길 때마다 마스크 월드 좌표를 다시 맞춰야 한다. 화살표는
사각형(자루) + 삼각형(촉) 두 조각뿐이라 잘라 그리는 편이 훨씬 단순하다.

완성 판정은 **제작 중이던 레시피가 사라진 순간**이다 — 서버가 "완성했다"는 신호를 따로
보내지 않지만, 비용을 미리 받는 구조라 진행 중에는 반드시 값이 들어 있다. 결과는 다음
제작을 걸 때까지 남겨 둔다(바로 지우면 눈 깜빡할 사이에 사라진다).

## 6. 검증

헤드리스 크롬으로 다섯 가지를 모두 확인했다.

- 걷기: D를 누른 채 찍은 연속 프레임에서 **다리가 교차한다**(고치기 전에는 여섯 장이 전부 같았다)
- 우클릭 사용: 체력 31 → 61(붕대 30%), 붕대 4 → 3개
- 좌클릭: 붕대 개수 그대로, 휘두르기 모션만 재생
- 휠: 슬롯 1 → 2 → 3(아래로), 3 → 2(위로)
- 코어 `E`: 코어 위에 키캡+화살표가 뜨고 오르내린다
- 제작: 화살표가 1.9초 → 1.3초 → 0.9초에 맞춰 차오르고, 완료 시 결과 상자에 돌도끼가 뜬다
- shared 530 + server 31 통과, 콘솔 오류 없음

## 7. 남은 것

- `E` 안내는 코어에만 있다. 티모시 상호작용에도 같은 그림을 쓸 수 있지만 아직 안 붙였다.
- 결과 상자는 **마지막으로 만든 것 하나**만 보여준다(제작 이력이 아니다).
- 휠은 인벤토리 전용이다. 창고나 모달 안에서는 아무 일도 하지 않는다.
