# 작업 보고서 — 렌더링 해상도 정책 변경

## 기획

초기 설정(480×270 캔버스를 통째로 확대)으로 만든 화면에서 **UI 글자를 알아보기 어렵다**는
지적이 나왔다. 원인을 확인하고 정책을 다시 잡는다.

## 과정

### 1. 원인 진단 — 두 가지가 겹쳐 있었다

**(a) 소수배 스케일 — 설정 실수**

`Phaser.Scale.FIT`은 창을 꽉 채우려고 소수배로 확대한다. 실제 캡처가 1195px 폭이었고
`1195 ÷ 480 = 2.49배`였다. 픽셀아트를 2.49배로 늘리면 어떤 픽셀은 2칸, 어떤 픽셀은 3칸이
되어 글자 획이 들쭉날쭉해진다.

**(b) 한글을 8px로 그리고 있었다 — 설계 실수**

영문 픽셀 폰트는 5×7px면 읽힌다. 저해상도 픽셀게임의 UI 관행이 여기서 성립한다.
**한글은 자소가 2~3개 조합되는 구조라 최소 11~12px, 편하게 읽으려면 16px이 필요하다.**
(한글 픽셀 폰트도 갈무리체 11px, 둥근모 16px이 기준이다)

480×270 캔버스에서 16px 폰트는 세로의 6%를 한 줄이 먹는다. HUD 몇 줄이면 화면이 잠식된다.
**"저해상도 캔버스 + 한글 UI"는 구조적으로 양립하지 않는다.** 처음 해상도를 정할 때
한글을 계산에 넣지 않은 것이 근본 원인이다.

### 2. 방식 비교

| 방식 | 평가 |
|---|---|
| 전부 저해상도 | 진짜 레트로. 영문 전용이면 가능하나 한글에서는 선택 불가 |
| 월드는 저해상도 버퍼, UI는 네이티브 해상도로 별도 렌더 | 가능하지만 Phaser에서 버퍼를 분리 관리해야 해 복잡 |
| **네이티브 캔버스 + 월드 카메라만 정수배 줌** | **채택.** 픽셀아트 룩 유지, UI 선명, 구현 단순 |

공통점은 **월드 해상도와 UI 해상도를 분리한다**는 것이다. 저해상도로 그려야 하는 건
스프라이트지 UI가 아니다.

### 3. 구현

```
변경 전:  480×270 캔버스 → FIT으로 2.49배 확대 (UI도 같이 뭉개짐)
변경 후:  캔버스 = 창 크기 (Phaser.Scale.RESIZE)
          GameScene 카메라 zoom = 2~4 (정수)  → 16px 타일이 32~64px
          HudScene  카메라 zoom = 1          → 글자를 14~28px로 선명하게
```

- `computeCameraZoom(w, h)` 를 `shared/constants.ts`에 순수 함수로 두고 유닛 테스트를 붙였다.
  좁은 축 기준 `floor`, 하한 2 / **상한 4**.
- **상한을 두는 이유**: 창이 클수록 월드가 넓게 보인다. 협동 게임에서 모니터 크기가 곧
  정보량 차이가 되면 안 된다.
- 캔버스가 창을 따라가므로 `Phaser.Scale.Events.RESIZE`에서 카메라 줌과 HUD 레이아웃을
  다시 계산한다. HUD는 좌표를 전부 `layout()`에 모아뒀다.
- **UI 스케일**: 월드가 4배로 확대되는데 HUD만 14px이면 화면이 따로 논다.
  `uiScale = clamp(zoom / 2, 1, 2)` 로 UI도 같이 키운다.

### 4. 함정 — 월드 안의 텍스트

닉네임 라벨은 `GameScene`에 있어서 카메라 줌의 영향을 받는다. 7px로 래스터화한 글자를
4배로 늘리면 결국 뭉개진다. `text.setResolution(zoom)`으로 **래스터화 해상도를 같이 올려야**
한다. `EntityRenderer#setZoom()`이 줌 변경 시 전 라벨에 반영한다.

### 5. 겸사겸사 고친 것

로컬 모드 스폰 좌표가 `(0, 0)`이라 코어 표시와 겹쳐 있었다. 서버(`GameRoom#onJoin`)와
동일하게 코어에서 떨어뜨려 놓았다.

### 남은 것

- **픽셀 폰트 미정.** 현재는 시스템 monospace다. 라이선스 확인 후 비트맵 폰트로 교체하면
  네이티브 해상도에서도 픽셀 느낌을 낼 수 있다 (16px 이상 권장).
- 창 크기별 시야 차이가 실제 플레이에서 문제가 되는지는 플레이테스트에서 확인한다.
  문제가 되면 줌 상한을 낮추거나 카메라 뷰포트를 고정 비율로 자른다.
